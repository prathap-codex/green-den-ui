# 🌿 Plant Selling Website

A responsive **Plant Selling Website** built using **HTML5** and **CSS3**. This project is designed with a clean, modern, and user-friendly interface, allowing users to explore plants and easily navigate through the website.

## ✨ Features

* 🏠 Home Page
* 🌱 Products Page
* 📞 Contact Page
* 📱 Fully Responsive Design
* 🎨 Modern and Attractive UI
* ⚡ Easy Navigation

## 🛠️ Technologies Used

* HTML5
* CSS3
* CSS Flexbox
* CSS Grid
